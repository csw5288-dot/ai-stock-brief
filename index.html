현재 Production 모델이 실패했다는 의미가 아닙니다.
Candidate A/B/C는 현재 모델을 대체하기 위해 시험한 개선 후보입니다. 일부 평균 수치가 좋아진 후보도 있었지만 중앙값·종목 동일가중·tail dependency 등 전체 채택 기준을 만족하지 못해 기존 Production 점수를 유지했습니다.

시장 특성에 따라 Technical Edge 구성요소의 유효성 차이가 확인되어, 단순 weight 조정보다 KOSPI에서 유효한 raw feature, 상대순위 기반 Edge, 시장 regime 조건을 별도로 재검토하는 방향으로 접근하고 있습니다. 새 후보가 만들어져도 새로운 universe 또는 Live OOS 결과로 다시 검증한 뒤 적용할 계획입니다.

외부검증 해석

“추가 검증 필요”는 모델이 무효라는 뜻이 아닙니다.
모든 시장과 종목군에서 동일한 강도의 Technical Edge가 재현됐다고 말하기에는 근거가 충분하지 않았다는 의미입니다. 반대로 KOSDAQ 효과와 Technical Risk처럼 재현된 항목은 별도로 확인했습니다.

분석 결과 읽는 법

처음에는 Technical Edge, Risk, Confidence 세 항목만 구분해서 보면 됩니다.

Technical Edge

현재 추세·Momentum·Relative Strength·Participation·Setup 등을 종합해 기술적으로 얼마나 유리한 위치인지 0~100점으로 나타냅니다. 상승확률로 해석하는 점수는 아닙니다.

Technical Risk

Edge와 별도로 변동성·downside 위험을 평가합니다.

Confidence

주가 상승 가능성이 아니라 현재 분석에 사용된 데이터의 품질과 분석 가능 상태를 나타냅니다.

현재 개발 방향

v2.6까지 분석 안정성, 검증, 자동화 기능을 구축했습니다.

현재 v2.7에서는 실제 분석 시점의 값을 고정한 뒤 미래 5·20·60 거래일 결과를 쌓는 Live Out-of-Sample Validation을 개발하고 있습니다.

동시에 시장별 유효성 차이가 확인된 Technical Edge는 KOSPI를 포함해 추가 연구 대상으로 관리하고 있습니다.

이용 전 참고사항

AI STOCK BRIEF는 특정 종목의 상승을 보장하거나 자동으로 매수·매도를 지시하는 서비스가 아닙니다. 시장 데이터와 기술지표를 빠르게 정리해 사용자가 직접 판단할 때 참고할 수 있는 정보를 제공하는 것을 목표로 합니다.
